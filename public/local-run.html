Локальный запуск

Скачиваешь проект, устанавливаешь зависимости и открываешь чат в браузере. Нужны Node.js и интернет. Данные для входа вводишь уже в чате, как на сайте.

01

Установить Node.js

Если Node.js уже установлен, сначала проверь версию. На Windows открой PowerShell и выполни:

node --version
npm.cmd --version

Этот проект проверен на Node.js 22.22.2 и npm 10.9.7. Для такого же запуска используй ветку 22.x, не ниже 22.12.

Если команды не найдены или версия старая, скачай Node.js с официальной страницы. Выбери версию 22.x и свою систему. Для обычного Windows-компьютера — установщик .msi для x64. npm устанавливается вместе с ним.

После установки закрой PowerShell, открой заново и повтори проверку выше. На macOS/Linux вместо npm.cmd используй npm.

02

Распаковать проект

  1. Скачай ZIP по ссылке в начале страницы. На Windows нажми на архив правой кнопкой и выбери «Извлечь всё…».
  2. Открой папку telegram-chat внутри распакованного архива. В ней должны лежать package.json, package-lock.json и README.md.
  3. В адресной строке Проводника напиши powershell и нажми Enter. Откроется окно команд в этой папке.

На macOS/Linux открой терминал и перейди в эту же папку. Команды ниже нужно выполнять там, где лежит package.json.

03

Запустить чат

В PowerShell выполни первую команду и дождись окончания. Потом выполни вторую:

npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 5173 --strictPort

npm.cmd ci скачает зависимости проекта. Эту команду достаточно выполнить после распаковки. Для следующих запусков нужна только вторая.

Когда в окне появится адрес http://127.0.0.1:5173/, открой его в браузере. Увидишь форму подключения к Telegram.

Окно PowerShell оставь открытым. Чтобы остановить чат, нажми в нём Ctrl + C.

Команды для macOS и Linux 
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort

Адрес в браузере тот же: http://127.0.0.1:5173/. Остановка — Ctrl+C в терминале.

04

Подключить Telegram

В форме введи idInstance и apiTokenInstance из своего кабинета GREEN-API. Это те же данные, с которыми подключаешься на сайте.

Нажми «Подключиться», введи номер собеседника с кодом страны и создай чат кнопкой +.

Дальше всё как в инструкции по переписке. Там же описаны настройки первого подключения.

Для одного подключения оставь только одну открытую вкладку чата: локальную или на сайте. После обновления страницы данные для входа и переписка в этой вкладке очистятся.

05

Если не запускается

Команда node или npm.cmd не найдена

Проверь, что Node.js установлен. Закрой окно команд и открой заново: после установки новое окно должно увидеть Node.js и npm.

Не найден package.json

Команды выполняются не в той папке. Вернись в распакованный проект и открой папку telegram-chat, где лежит package.json. Открой PowerShell оттуда.

Порт 5173 уже занят

Если чат уже запущен в другом окне, используй его или останови Ctrl+C. Можно выбрать другой порт:

npm.cmd run dev -- --host 127.0.0.1 --port 5174 --strictPort

Тогда адрес — http://127.0.0.1:5174/. На macOS/Linux замени npm.cmd на npm.

Зависимости не скачиваются

Проверь интернет. Если npm сообщает о неподходящей версии Node.js, установи 22.x не ниже 22.12. После этого снова выполни npm.cmd ci.

Форма открылась, но Telegram не подключается

Сам проект уже запущен. Проверь данные для входа и статус подключения в кабинете GREEN-API. Подсказки есть в инструкции по переписке.
